AI Safety · LLM Evaluation

LLM Sycophancy in Financial Advice

Pre-registered, blinded eval measuring whether frontier LLMs shift financial recommendations based on user-expressed priors. Built a 150-scenario dataset across 10 asset classes and 4 risk tiers. 360 API calls across Claude Sonnet 4.6 and GPT-4o-mini, scored by a Claude Opus 4.7 judge blinded to user framing. Found 0% symmetric sycophancy but two distinct framing effects: GPT-4o-mini shows 40% asymmetric bullish deference; Claude shifts response posture (action guide vs. interrogation) without flipping the substantive recommendation. Open-sourced eval harness, 150-scenario dataset, and judge rubric.

Python Claude Sonnet 4.6 Claude Opus 4.7 GPT-4o-mini pandas scipy

AI Safety · LLM Evaluation · Political Bias

Political Framing Bias in LLM Refusal Behavior

Pre-registered eval testing whether frontier LLMs show asymmetric refusal rates when identical economic policy requests are framed with left-coded vs. right-coded language. Built a 60-pair dataset across 12 policy topics (tax, trade, labor, housing, energy, fiscal policy, and more) with matched LEFT / NEUTRAL / RIGHT framings for the same underlying task. Ran 540 API calls across Claude Sonnet 4.6, Claude Opus 4.7, and GPT-4o-mini, scored by a Claude Opus 4.7 judge. Found strong, consistent right-coded refusal bias across all three models: each refuses right-framed requests ~15–16% of the time while refusing identical left-framed requests 0% of the time (RRD ≈ −0.15). Five pairs hit maximum asymmetry (RRD = −1.0), concentrated in tax policy, energy, housing, and fiscal policy.

Python Claude Sonnet 4.6 Claude Opus 4.7 GPT-4o-mini pandas scipy

Hallucination Rates in LLM-Based AML Adverse Media Screening

Pre-registered empirical evaluation measuring false positive rates and hallucinated risk claims when frontier LLMs are used for AML adverse media screening. Building a dataset of 100 synthetic entities across five ground-truth categories (clean, PEP, sanctioned, fraud, adverse media), each paired with a structured news article. Testing whether models fabricate specific adverse associations absent from the source material — sanctions links, fraud convictions, PEP status — and whether extended thinking reduces hallucination rates. Motivated by the deployed failure mode of AI-generated adverse media flags causing innocent individuals to be debanked at scale.
