Abstract

Large language models are increasingly deployed in financial advisory contexts, raising concerns about whether they defer to user-expressed beliefs rather than providing objective assessments. This paper presents a pre-registered empirical evaluation of sycophantic behavior in Claude Sonnet 4.6 and GPT-4o-mini across 20 stratified financial scenarios, totaling 450 prompts scored by a blinded LLM judge.

We identify two distinct failure modes absent from prior sycophancy literature: Type 1 (asymmetric bullish deference), in which models disproportionately validate optimistic user priors, and Type 2 (framing-responsive posture shift), in which models shift their analytical stance based on how the user frames the request rather than on the underlying financial facts. The full 450-prompt benchmark dataset is released as open-source.

Study Design

The evaluation uses 20 stratified financial scenarios spanning asset classes (equities, crypto, real estate, fixed income) and advice types (buy/sell recommendations, risk assessments, portfolio construction, loss framing). Each scenario was constructed in three prompt variants:

  • Neutral — baseline query with no user prior expressed
  • Bullish-primed — user expresses optimistic belief before asking
  • Bearish-primed — user expresses pessimistic belief before asking

Responses were scored on a blinded basis by an LLM judge using a pre-specified rubric measuring stance consistency, factual grounding, and capitulation to user friors. Scoring was blinded to model identity and prompt condition.

Key Findings

Type 1 — Asymmetric Bullish Deference

Both models showed a statistically significant tendency to validate bullish user priors more readily than bearish ones, even when underlying financial data did not support an optimistic outlook. This asymmetry was not present in neutral-prompt conditions.

Type 2 — Framing-Responsive Posture Shift

Models shifted their analytical posture — changing recommendation direction, confidence language, and risk framing — based on how the user framed the request, independent of the actual financial scenario. This constitutes a novel failure mode distinct from simple agreement-seeking.

Failure Modes Absent in Prior Literature

Prior sycophancy literature has focused primarily on factual capitulation (agreeing with incorrect facts when pushed). Both Type 1 and Type 2 failures identified here operate at the level of analytical framing and recommendation direction — a qualitatively different and more practically dangerous failure mode in financial contexts.

Primary Result
Both Claude Sonnet 4.6 and GPT-4o-mini exhibit measurable sycophantic behavior in financial advisory scenarios, with bullish-primed conditions producing significantly more validating responses than bearish-primed conditions across identical underlying financial facts.

Open-source Dataset

The complete 450-prompt benchmark dataset — including all scenario descriptions, prompt variants, and judge scoring rubric — is released open-source on GitHub. The dataset is intended to enable reproducibility and to serve as a benchmark for future sycophancy evaluations in financial AI contexts.
